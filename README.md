## 📖 Acerca del Proyecto

**IT Assets (Inventario Vivo)** es una aplicación web diseñada para simplificar la gestión de activos tecnológicos en pequeñas y medianas organizaciones[cite: 1, 2]. Nació de la necesidad de dejar atrás las hojas de cálculo dispersas, centralizando el control del **hardware, software y redes** en un solo lugar[cite: 2]. 

Con esta plataforma podrás saber en tiempo real **qué tienes, dónde está y qué necesita atención** de forma rápida y sin costos ocultos[cite: 2].

---

## ✨ Características Principales

* **📊 Dashboard General:** Resumen visual e interactivo del estado general de los activos, métricas de equipos operativos, en mantenimiento o con incidencias[cite: 1].
* **🛠️ Gestión de Hardware, Software y Redes:** Clasificación detallada por categoría con números de serie, marcas, modelos y especificaciones técnicas[cite: 2, 3, 4].
* **📍 Control de Ubicaciones y Usuarios:** Asignación de responsables y espacios físicos para cada dispositivo[cite: 3, 4].
* **🚨 Alertas y Notificaciones:** Avisos tempranos sobre equipos con fallas, licencias próximas a vencer o elementos sin responsable asignado[cite: 1].
* **🔍 Búsqueda Avanzada y Filtros:** Localización inmediata de activos mediante filtros por tipo, estado y ubicación[cite: 3].
